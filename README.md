# 🌿 Raíz Natural – Landing page

Página web para una tienda de cosméticos naturales (proyecto demo de portafolio).

🔗 **Ver en vivo:** https://raiz-natural-lina.netlify.app

## Características

- Diseño responsive (computador y celular)
- Catálogo de productos con precios y etiquetas
- Secciones de beneficios y opiniones
- Formulario de contacto que arma el mensaje y lo envía por WhatsApp
- Animaciones al desplazarse (Intersection Observer)
- Botón flotante de contacto

## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid, media queries, animaciones)
- JavaScript
- Google Fonts
- Publicado en Netlify
